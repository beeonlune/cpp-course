void test ( Person const & person )
{
	std :: cout << " test : " << person.name () << ’\n’;
	if ( person.grade () == 10 || person.salary () > 1’000 ’000)
	{
		save ( Status :: success , person.id () ) ;
	}
	else
	{
		save ( Status :: failure , person.id () ) ;
	}
}

Нормальное ветвление выполнения:

* конструкция if / else
* логическое ИЛИ (||): если выражение person.grade() == 10 истинно, программа переходит к телу if, пропуская вызов функции person.salary() и оператор >

Потенциальные места генерации исключений:

* вызовы person.name(), person.grade(), person.salary() и person.id() могут выбросить исключения (так как их реализация скрыта и мы про них ничего не знаем)
* внешняя функция save может сгенерировать исключение в процессе выполнения (например, ошибка доступа к файлу или БД)
* operator<< может выбросить std::ios_base::failure или исключение из перегруженного оператора << для типа, возвращаемого person.name()
* операторы сравнения (== и >): если grade() и salary() возвращают пользовательские классы, а не примитивные типы, перегруженные для них операторы сравнения могут генерировать исключения
